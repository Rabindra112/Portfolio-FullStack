# Rabindra Kumar Mahato - Full Stack Portfolio

## Stack
Frontend: React, TypeScript, Tailwind CSS, React Router, Axios
Backend: Java 17, Spring Boot, Spring Security, JWT, Spring Data JPA, Hibernate, MySQL, Bean Validation, Lombok, Maven

## Run MySQL
CREATE DATABASE rabindra_portfolio;

## Run backend
cd backend
mvn spring-boot:run

Default admin:
username: admin
password: admin123

Change the default credentials before deployment.

## Run frontend
cd frontend
npm install
npm run dev

Put your real `profile.jpg` and `resume.pdf` in `frontend/public/`.

The portfolio intentionally does not include QA/Testing, Blog, or System Architecture sections.
